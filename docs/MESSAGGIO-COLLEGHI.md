# Testo pronto per colleghi

## Versione email

Oggetto:
Installazione script Tampermonkey per export missioni U-Web

Testo:

Ciao,

ti condivido lo script Tampermonkey per esportare da U-Web Missioni:

- richiesta PDF della missione
- allegati della missione
- file ZIP finale con una cartella per ogni missione

Per installarlo:

1. apri in Chrome o Edge il file `uweb-export-missioni.user.js`
2. Tampermonkey si aprira automaticamente
3. clicca `Install`
4. vai su U-Web Missioni:
   `https://cnr.u-web.cineca.it/appautmis/listaautmis#!/listaautmis`
5. effettua il login se necessario
6. nella pagina comparira il pannello `Export missioni in ZIP`
7. imposta i filtri desiderati e clicca `Scarica ZIP missioni`

Nota:
lo script funziona solo sulle pagine U-Web Missioni e usa la tua sessione gia autenticata.

Se hai problemi in installazione o uso, scrivimi.
